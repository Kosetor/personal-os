# Personal OS Learning

Система ежедневного обучения управленческим навыкам для госслужбы.

- **Статья дня** с инфографикой и аудио-подкастом (читать или слушать)
- **Адаптивный тест** по алгоритму FSRS (последняя тема + повторения)
- **Напоминания в Telegram**, если материал не изучен
- **Статический сайт** на GitHub Pages: статья дня, архив, граф тем прогрессии
- **Приватность**: вся персональная информация — локально, в Pages — только
  обезличенный снапшот

## Структура

```
site/          — публикуемая статика (Pages деплоит эту папку)
content/       — исходники статей (published/ и drafts/)
.github/workflows/ — деплой на GitHub Pages
```

Приватные данные (learning.db, нормативка, логи) — в `~/personal-os-private/`,
**вне git**.

## Для агентов
