# 🖥️ Personal OS — стартовая страница браузера

Персональный дашборд для управления Hermes-агентами и быстрого доступа к ключевой информации.
Хостится на GitHub Pages, бэкенд не требуется — вся логика в браузере.

**Сайт:** https://kosetor.github.io/personal-os/

## Что на странице

1. **Агенты** — карточки с аватарами работающих Hermes-агентов и их текущим статусом:
   активен / не активен / думает / ищет информацию. Статусы обновляются автоматически.
2. **Обратная связь** — выбор агента из списка и отправка ему команды (Ctrl+Enter — быстрая отправка).
3. **Последний ответ** — агент, текст команды и его ответ на последний запрос + мини-история из 5 обменов.
4. **Инфо** — погода в Благовещенске (Open-Meteo), ваш IP с флагом страны, текущее время в Благовещенске (UTC+9).

## Включение GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment**: Source = **Deploy from a branch**, Branch = **main**, папка **/ (root)** → **Save**.
3. Через 1–2 минуты сайт будет доступен по адресу https://kosetor.github.io/personal-os/

## Настройка агентов (config.js)

Все настройки — в файле `config.js`. Для каждого агента можно указать:

| Поле | Назначение |
|---|---|
| `avatar` | Эмодзи или URL картинки |
| `statusUrl` | GET-эндпоинт статуса. Ответ: `{"status": "active"}` — возможны `active`, `thinking`, `searching`, `inactive` |
| `commandUrl` | POST-эндпоинт команд. Запрос: `{"agent": "id", "command": "...", "ts": "..."}`. Ответ: `{"reply": "..."}` |

Если поля пустые — агент работает в демо-режиме (случайные статусы, имитация ответов).

⚠️ **Важно:** GitHub Pages работает по HTTPS, поэтому эндпоинты агентов тоже должны быть
доступны по HTTPS (иначе браузер заблокирует mixed content) и отдавать заголовок
`Access-Control-Allow-Origin` (CORS). Удобный вариант — опубликовать API агентов через
Caddy/nginx с сертификатом или Tailscale Funnel.

## Установка стартовой страницей

- **Chrome / Edge:** Настройки → При запуске → Открыть определённую страницу → добавить `https://kosetor.github.io/personal-os/`
- **Firefox:** Настройки → Основные → Домашняя страница и новые окна → URL страницы
- Для открытия в каждой новой вкладке используйте расширение типа «New Tab Redirect».

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `style.css` | Тёмная тема оформления |
| `config.js` | ⚙️ Настройки: агенты, эндпоинты, город |
| `app.js` | Логика: опрос статусов, команды, погода, IP, часы |
