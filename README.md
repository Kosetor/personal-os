# Personal OS Learning

Система ежедневного обучения управленческим навыкам для госслужбы.

- **Статья дня** с инфографикой и аудио-подкастом (читать или слушать)
- **Адаптивный тест FSRS и напоминания** — часть внешней приватной системы
  hermes_a; их реализация и результаты отсутствуют в этом репозитории
- **Статический сайт** на GitHub Pages: статья дня, архив, граф тем прогрессии
- **Приватность**: вся персональная информация — локально, в Pages — только
  обезличенный снапшот

## Структура

```
site/          — публикуемая статика (Pages деплоит эту папку)
content/       — исходники статей (published/ и drafts/)
.github/workflows/ — деплой на GitHub Pages
```

Приватные данные (learning.db, нормативка, логи) — в `~/personal-os-private/`,
**вне git**.

## Для агентов

Веб-тестов на сайте пока нет. Кнопка «Прочитано» хранит отменяемую отметку
для статьи только в браузере; она не передаёт результаты агенту и не меняет FSRS.
Количество статей и снимок изученных тем показаны отдельно. Дата снимка видна
на главной и странице прогресса.

Проверка перед публикацией (Python 3.12+, Node.js 22; сторонние пакеты не нужны):

```sh
python scripts/check_site.py
node --test tests/*.test.cjs
```

CI проверяет ссылки, наличие медиа, согласованность публичных JSON и поведение
отметок о чтении. Он не проверяет реальные учебные ответы или внешнее расписание.
После изменения генератора на приватном устройстве нужно перенести в него
актуальные шаблоны сайта. Порядок восстановления — в `AGENTS.md`, раздел 6.2.

Визуальные правила описаны в `GRAPHIC-REALISM.md`. Токены и адаптация находятся
в `site/assets/mgr-theme.css`. Использованы `ic-crosshair-square.svg` и
`ic-circle-grid.svg` из [Graphic Realism Design System](https://github.com/Kosetor/graphic-realism-design)
по лицензии MIT; исходные файлы находятся в `icons/mgr-geometry/` того репозитория.

Правила работы — в `AGENTS.md` (hermes_a) и `AGENTS-HERMES-B.md` (hermes_b).
